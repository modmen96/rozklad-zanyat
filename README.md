# Сайт розкладу занять

Статичний сайт HTML + Bootstrap 5 із м'якою теплою палітрою, адаптивним оформленням і двома вбудованими календарями.

## Перед публікацією

У `index.html` знайдіть `YOUR_PUBLIC_CALENDAR_ID` та замініть цей текст на ID публічного Google Calendar.

Як знайти ID:
1. Відкрийте Google Calendar на комп'ютері.
2. Перейдіть у **Налаштування**.
3. Виберіть календар, який потрібно показувати на сайті.
4. Знайдіть **Інтеграція календаря → Ідентифікатор календаря**.
5. Скопіюйте ID і замініть `YOUR_PUBLIC_CALENDAR_ID` у `index.html`.

У налаштуваннях доступу потрібно дозволити публічний перегляд. Не використовуйте цей календар для приватних нотаток або персональних даних студентів. Для показу лише зайнятих годин створюйте події з нейтральними назвами, наприклад «Зайнято».

## Календар запису

У файлі вже вказане посилання на Google Appointment Schedule. Якщо вбудований календар не показується в певному браузері, скористайтеся кнопкою **Перейти до запису**. Якщо Google надає окремий код вбудовування для сторінки запису, його можна вставити замість першого iframe.

## Публікація через GitHub Pages

1. Увійдіть на https://github.com і створіть репозиторій, наприклад `rozklad-zanyat` (для GitHub Free зробіть його Public).
2. Завантажте `index.html` у корінь репозиторію через **Add file → Upload files**.
3. Натисніть **Commit changes**.
4. Відкрийте **Settings → Pages**.
5. У **Build and deployment** виберіть **Deploy from a branch**, гілку `main` і папку `/(root)`, натисніть **Save**.
6. Дочекайтеся публікації та відкрийте адресу, яку покаже GitHub Pages. Зазвичай вона має вигляд `https://ВАШ-ЛОГІН.github.io/rozklad-zanyat/`.

Офіційна інструкція: https://docs.github.com/en/pages/quickstart

## Перевірка
- Відкрийте сайт у приватному/інкогніто-вікні.
- Перевірте сайт на телефоні, зокрема в Safari на iOS.
- Переконайтеся, що календар показує правильний час за Києвом.
- Перевірте бронювання в тестовому слоті, щоб випадково не створити реальний запис.
